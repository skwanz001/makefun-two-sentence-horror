One horror story of exactly two sentences (136 characters), written to `/output/entry.txt` by `main.py` (Python 3.13, standard library only).

> A letter arrived today in my own handwriting, dated next Tuesday. It says only: 'Don't answer the door — he sounds exactly like me now.'

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
